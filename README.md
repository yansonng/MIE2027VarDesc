# MIE2027VarDesc

Supplementary material for *Can Patient-Specific Information Improve Medication-Based Risk Assessment? A Machine Learning Study of Bleeding-Related Inpatient Admissions* (MIE 2027).

| File | Contents |
|---|---|
| [variables.md](variables.md) | Definitions of all 65 model variables: 37 medication-related, 28 patient-related |
| [supplement.md](supplement.md) | S1: how Janusmed and the models are compared at equal alert volumes ("flagging"), with a worked example. S2: learner comparison (XGBoost vs logistic regression). S3: hyperparameters and the tuning sensitivity analysis. S4: temporal validation (trained on 2020–2022, tested on 2023). S5: sensitivity analyses, medication-list completeness and the outcome code sets |

No patient data are included. The pseudonymised patient data and analysis code are not publicly available.
